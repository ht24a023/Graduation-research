# J.A.R.V.I.S.機能比較・改修記録

確認日：2026-11-01 / 対象：Documents/Codex/sotuken

映画で描かれる能力を実用的なPCアシスタントの機能へ置き換えて比較しました。映画の全場面を検証した網羅表ではありません。実装状況と、このPCで実際に動作を確認できた範囲は分けています。

## 今回追加した12の画面

MISSION（予定・タスク）、BRIEFING（今日の状況）、KNOWLEDGE（資料検索・取込）、VISION（静止画認識）、VOICE（呼びかけ入力）、SPATIAL（3Dモデル表示）、DEVICE（PC操作）、CONNECT（家電・メール・カレンダー）、LAB（計算・単位変換）、NEWS（ニュース）、NETWORK（接続監視）、SYSTEMS（診断・機能一覧）。既存の左右移動・ピン留め・レイアウト保存・中央チャットと統合しています。

## 機能の棚卸し

「既存」「追加」はコードの実装状況です。「条件あり」は機器・API・ブラウザー・権限等が必要です。「機器が必要」「別構成が必要」は実現可能性がありますが、現状の実装では利用できません。

## 実際に確認できたこと

検証結果：機能単体・実HTTP/Chrome操作・既存チャット・カード連携・レイアウトの計40テストが通過しました。外部機器・アカウントの実接続は下記の確認状況に従います。

- 一時保存先を分けた検証サーバーとChromeで、予定の追加・編集・再読込、CHAT中のリマインダー抑制、文書取込とAND検索、計算・単位変換、画像取込と消去、OBJの表示と操作を確認。実ユーザーの予定・文書へ検証データは追加していません。
- 呼びかけ機能は認識エンジンを差し替えた操作検証で、手動開始・停止・認識結果から入力欄への反映を確認。実マイクの認識精度・長時間待受は未確認です。
- BBC WORLDは実フィード15件、NASA NEWSは実フィード10件を取得。この記事件数は確認時点の結果で、常に同じ件数を保証しません。
- このPCのOllamaでは画像対応モデルの検出結果は0件。画像認識APIの入出力・条件判定は検証済みですが、実モデルでの認識・OCRは未確認です。モデルは自動でダウンロードしていません。
- Home AssistantとMicrosoft Graphは未設定です。APIアダプターを実装し、未設定時の表示とHome Assistantの要求形式を検証しました。家電操作・実メール・実予定取得は未確認です。
- ネットワーク接続一覧はこの実行環境でGetExtendedTcpTableが失敗。未取得として表示します。通常権限のサーバーで動作確認が必要です。
- Windowsのアプリ起動・メディアキー操作は許可リストで実装。検証中にユーザーのアプリを起動したり再生状態を変更したりはしていません。
- カメラと共有画面の実機許可、Windows通知補助アプリの登録・OS権限・実通知受信は未確認です。

## 実現可能だが追加条件が必要な範囲

1. ロボット・外部センサー：対象機種と制御APIが必要です。Home Assistantで扱える機器は今回の状態表示・許可した操作に接続できますが、ロボットの動作計画や自律移動は未実装です。
2. CAD編集・物理解析：今回の3D表示は形状確認までです。設計編集や強度・流体解析にはCAD/解析ソフト、モデル形式、材質、境界条件の指定と専用連携が必要です。
3. 任意ソフトの自律操作：今回のPC操作はメモ帳・電卓・エクスプローラーとメディア操作までです。任意アプリの認識・操作・復旧を一律に保証する自律エージェントは未実装です。対象アプリと許可範囲が必要です。
4. 画面を閉じている間のウェイクワード・予定通知：ブラウザーを閉じた状態での常駐処理は未実装です。専用音声サービス・Windowsタスクや通知補助アプリへの追加接続が必要です。
5. 外部サービスへの書込：メール送信・外部予定の作成・削除は今回追加していません。認証・操作内容確認・重複送信防止まで含めた連携が必要です。

上記は不可能として除外していません。今回の改修だけで、実現可能なすべての拡張が完成したという扱いにはしていません。

## 通常のPCアプリでは再現しないもの

- **空中に触れる立体ホログラム**：通常のPC画面だけでは映画と同じ空間投影・触覚を再現できない。画面上のHUDは実装対象。
- **架空のリアクター・スーツ・瞬間的な物理修復**：制御対象そのものが存在しない。実在するセンサーや機器は接続仕様があれば別途対応可能。
- **万能で誤りのない推論・未来予知**：事実として保証できない。根拠・取得失敗・未確認の表示で補う。

## 利用とデータの扱い

サーバーを再起動してブラウザーを再読み込みし、MISSIONから表示を選択してください。予定はdata/mission_board.jsonに保存します。画像・カメラ・画面は選択した静止画だけをローカルOllamaに送り、画像ファイルや会話履歴には保存しません。メール・外部予定・家電状態は手動取得し、AIへ自動送信しません。呼びかけ認識はブラウザー提供元へ音声が送信される場合があります。

接続変数・上限・詳しい動作はプロジェクトのREADMEを参照してください。
