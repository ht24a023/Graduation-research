# sotuken：ローカル優先AIアシスタント

## 起動

Windows PowerShellで、このフォルダに移動して実行します。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe local_ai_server.py
```

ブラウザーで http://localhost:8000/ を開きます。変更前から起動している場合はサーバーを再起動し、ブラウザーを強制再読み込みしてください。

ローカルLLMにはOllamaと `config.py` の指定モデルが必要です。クラウド利用には `.env` のAPIキーを設定します。キーなしでも画面・専用ツール・ローカル機能は起動できます。

## 画面と情報パネル

中央チャットの位置と画面下の入力欄は固定し、会話履歴だけがスクロールします。左右に必要なパネルを開けます。複数のパネルや長文がある場合は、パネル内だけをスクロールします。

天気、地図、現在地、翻訳、文書、システム情報、Web検索・Wikipedia、YouTube、処理履歴、性能、QRコードに対応しています。

- 上部のボタンで手動開閉します。パネルの「⇄」で左右を変更できます。
- 実行したツールの戻り値にカード種別を付け、SSEで自動表示します。AIの回答文からカード内容を推測しません。
- 自動切替で閉じるのは、自動表示され、手動操作・ピン留めされていないパネルだけです。手動で開いたパネルは維持します。
- 「×」で対象だけ閉じ、「すべて閉じる」でピンも含めて収納します。処理中に閉じたパネルは、その処理の完了通知では再び開きません。
- 「自動表示」をオフにすると、手動で選択したパネルだけ表示します。
- 翻訳では原文、結果、言語の選択、外部翻訳画面へのリンクを表示します。取得に失敗した場合はエラーを表示し、結果を補いません。
- 文書パネルには既存の文書一覧・閲覧・編集機能を接続しています。文書IDに続けて「を表示して」と入力できます。
- YouTubeは取得できた動画のタイトル・サムネイル・視聴リンクを表示します。アクセス制限時は取得失敗と検索リンクを表示します。
- QRコードは `qrcode` を使ってPC内で生成し、SVGで保存できます。QRの文字列を外部QRサービスに送りません。

例：`大阪の天気を教えて` / `こんにちはを英語に翻訳して` / `CPUの使用率を教えて` / `https://example.comをQRコードにして`

## AIコアとシステムモニター

AIコアは待機、音声検出、音声認識、意図判定、ツール実行、ローカル推論、クラウド推論、回答、エラーを実際のイベントに連動して表示します。同心円、分割リング、傾斜リング、目盛り、走査線、粒子は固定した少数のDOM要素を使います。非表示タブではコアのアニメーションを止め、動きを減らすOS設定にも従います。

システム情報はブラウザーを開いた端末ではなく、Pythonを実行中のPCの値です。約2.5秒ごとに更新します。通信速度は差分が必要なため初回は「計測中」です。ディスクはアプリのあるドライブ、通信量はPC全体です。

CPU温度はOSの対応センサーのみ、GPUは `nvidia-smi` が利用できるNVIDIA機のみ対応（15秒ごと採取）。非対応・未取得の値は推測しません。端末位置はユーザーの許可が必要です。IP推定の誤差は不明、手動位置は地域の代表地点として区別します。

## 計測と研究用の記録

- サーバー：`perf_counter()` で意図判定、各ツール、ローカルAI、クラウドAIを分けて計測します。ツール内部で使うLLMも接続層で計測します。集計・CSVには内包する別処理を除いた固有時間を使い、二重計上を防ぎます。個別ステージの履歴には実際の開始〜完了時間も残します。
- ブラウザー：送信からの経過時間を100ms間隔で更新し、初回テキスト表示、テキスト表示完了、音声出力完了を区別します。
- 音声認識：音声入力操作から認識結果の確定まで。発話時間を含み、認識エンジン内部だけの時間ではありません。手入力し直した場合はその認識時間を送信データに付けません。
- 音声合成：ブラウザーは内部の生成時間を公開しないため「計測不可」と扱います。合成依頼から発話開始までの待ち時間、実際の再生時間、送信から発話完了までを別々に記録します。
- 現在の通常応答は一括テキストです。サーバーのテキスト生成完了と、ブラウザーの初回表示時刻を区別します。生成中の最初のトークン時刻は未計測（空欄）です。
- サーバー時計とブラウザー時計を直接引き算しません。計測方法の異なる値を同じ時間として扱いません。

各会話の折りたたみ表示、「処理履歴」「性能」から結果を確認できます。`data/processing_log.jsonl` にリクエストIDとセッションIDを付けて保存し、性能パネルから詳細CSVを保存できます。CSVは直近100件までです。未実行・計測不可は空欄で、0秒と区別します。`PROCESSING_LOG_PATH` 環境変数でログ先を変更できます。

## 音声

対応ブラウザーのSpeechRecognitionとマイクAPIを使用します。HTTPSまたはlocalhostが必要です。ブラウザー提供元へ音声が送信される場合があることを画面に明記しています。認識結果は入力欄に入れ、送信は手動です。検出中のリングは実マイク音量で脈動します。

読み上げは初期状態でオフです。ブラウザー音声合成の開始・終了イベントに合わせて発光します。出力波形は公開されないため、回答中の光は音量の実測ではありません。

## 外部サービスとテスト

外部検索・天気・翻訳・動画情報は、各サービスの制限や障害の影響を受けます。取得失敗をデモデータや推測値で成功に置き換えません。翻訳の別プロバイダーへの自動転送は実装していません。

天気APIの仕様確認：[Open-Meteo公式ドキュメント](https://open-meteo.com/en/docs)。`current` の `time` は出力に含まれる時刻であり、取得変数として指定しません。

開発用ライブラリは `requirements-dev.txt`、主な新規テストは `tests/test_workbench.py` と `tests/test_workbench_browser.py` です。ブラウザーテストは `e2e` マーカーを付け、Chromeを使用します。既存の `test_search_fix*.py` は実サービスを呼ぶ検証スクリプトなので、オフライン単体テストとは分けて実行してください。

## PC時計とWindows通知（追加改修）

ヘッダーの時計は `/system/clock` からバックエンドPCのシステム日時・UTCオフセットを取得し、24時間表記で秒更新します。時差を固定のAsia/Tokyoや閲覧端末に依存させません。日付・曜日の更新、秒リング、数字幅の固定、15秒間隔の再同期に対応します。

右側の `CHAT / SEARCH / INFO` で表示を切り替えます。CHATは会話の確認用で、入力は引き続き中央です。CHAT中・非表示タブでは通知を出さず、抑制中の通知を後から再生しません。既存の動的パネル、AIコア、システム情報の処理は継続します。

`SETTINGS` で通知表示のオン/オフ、2〜15秒の表示時間（既定5秒）、重要扱いのアプリ名を変更できます。通常はシアン、指定アプリはオレンジ。キューによる順番表示、右からのスライド、フェードアウト、×による個別終了に対応します。ポップアップは右領域に重ね、チャットや入力欄を押し下げません。

通知はWindows専用の補助アプリが公式 `UserNotificationListener` APIで取得します。初期状態はOFF。Windowsへのアプリ登録と利用者による通知アクセス許可が必要で、コードのビルドだけでは実OS通知は読み取れません。ビルド済み実行ファイルと登録スクリプトを `native/NotificationBridge/` に用意しています。詳細は同フォルダのREADMEを確認してください。

通知本文は最大60秒のメモリー保持だけで、会話・研究ログ・ファイルへ保存せず、AIや外部サーバーに送りません。通知のAPIはバックエンドPC内の接続に限定し、補助アプリとの通信はランダムトークンで認証します。別のスマートフォンやPCから開いたブラウザーには通知内容を返しません。


## MAX HUD と追加操作（2026-10-31）

ヘッダーの MAX HUD / FOCUS で情報量を切り替えます。SETTINGS の HUD表示情報から13種類の枠を個別に隠せます。モード、非表示の枠、手動で開いたパネルとピン留め・左右配置、読み上げ設定は、このブラウザーに記憶します。

PCの実測情報には、コア別CPU、メモリ・ディスク空き容量、通信量、メモリ使用量上位プロセス、サーバー稼働時間を表示します。プロセス一覧は最大6件・15秒間隔です。取得非対応のGPU・温度は未取得と表示し、実測の更新が12秒以上止まると古い値であることを示します。SETTINGS から実測スナップショットをJSON保存できます。

処理履歴は要求文・ツール名・処理経路で検索し、成功／失敗で絞り込めます。JSON保存には会話の要求文を含むため、保存先の取り扱いに注意してください。性能パネルに成功率、サーバー処理時間の平均・中央値・P95を表示します。グラフは同じサーバー計測だけで比較し、ブラウザー計測は別項目に表示します。

Ctrl + K でコマンド検索、Ctrl + Shift + K で入力欄へ移動できます。読み上げは「読み上げ停止」または Escape で停止できます。処理中は会話ID変更と「新しい会話」を一時停止し、別会話への結果混入を防ぎます。


## COMMAND・LAYOUT・TIME（2026-11-01）

- ヘッダーのCOMMANDまたはCtrl＋Kで操作を検索できます。日本語・英語の検索、上下キー、Enter、Escapeに対応。入力途中のチャット本文は保持します。Ctrl＋Shift＋Kで入力欄へ直接移動します。
- LAYOUTで、HUDの表示枠、パネルの左右・開閉・ピン留め、右側表示モード、自動表示を名前付きで保存できます。最大12件。同じ名前では更新し、「全情報」「会話に集中」「調べもの」の初期レイアウトも選べます。会話本文やAPIキーはレイアウトに含めません。
- TIMEで複数タイマー（最大12件、1秒〜24時間）とストップウォッチを操作できます。タイマーの一時停止・再開・リセット、完了分の整理、ストップウォッチのラップ（最大32件）に対応します。完了したタイマーはヘッダーで表示します。音やWindows通知は発生させません。
- これらの保存先はこのブラウザーのlocalStorageで、他のPC・ブラウザーとは同期しません。タイマーとストップウォッチは再読込後も保存した開始・期限時刻から復元します。表示中の経過時間は単調時計を使い、非表示からの復帰や再読込時は保存したシステム時刻と照合します。ブラウザーを閉じている間の通知は行わず、次に開いたときに期限を確認します。
- 単体の時間計算検証は `node tests/task_state_check.cjs`、実ブラウザーの操作検証は `tests/test_taskdeck_browser.py` です。


## 常設HUDとCONTROL（2026-11-01）

左側のAIコア、PC情報、CPUコア、プロセス、容量・通信、トレンドは常設です。FOCUSや別パネルへの切替でも非表示にしません。AIコアは左側の内部スクロール中も上部に残ります。画面幅900px以下では入力欄を優先する既存のモバイル表示を使います。ブラウザーを開いている間はPC監視の取得を続けます（OSによる背景タブの実行制限は受けます）。

入力欄のAI ASSIST、入力待機中の分析表示、定型入力ボタンを撤去しました。

ヘッダーのCONTROL、またはAlt + Jで操作コンソールを開けます。検索してEnterで先頭の操作を実行し、Escapeで閉じます。情報パネルの呼び出し、全画面切替、最後の回答のコピー、読み上げ停止、PC診断テキストの保存に対応します。

SYSTEM WATCHは実測でCPU 95%以上が3サンプル継続、RAM 90%以上、ディスク95%以上、電源未接続で電池20%以下を注意表示します。値が取得できない項目は正常と断定しません。12秒以上更新されない情報は更新停止と示します。警告は表示のみで、アプリの強制終了などはしません。

TASK TIMERは1〜180分、開始・一時停止・再開・リセットに対応し、状態をこのブラウザーに保存します。ページを再読込しても再開でき、期限を過ぎると左側に完了を表示します。音やOS通知は出しません。ACTIVITYには実際の処理開始・段階・完了・警告の変化を直近30件表示します。入力文はこのイベント欄に保存しません。

## MISSION：J.A.R.V.I.S.機能拡張（2026-11-01）

ヘッダーの **MISSION** を開き、パネル上部の選択欄から12種類の表示を切り替えます。COMMAND / CONTROLからも検索できます。パネルは既存と同じ左右移動・ピン留め・開閉・LAYOUT保存に対応します。

- **MISSION**：タスク、予定、リマインダー。件名・日時・詳細・優先度、編集、完了、削除、今日の絞込、JSON追加取込・保存、ICS書出。`data/mission_board.json`へ保存します。通知は画面を開いている間だけ。CHAT中・背景タブではポップアップを抑制し、抑制分は後から再生しません。ヘッダーの期限件数は残します。
- **BRIEFING**：未完了・期限到来・直近予定、実測PC情報、画面で取得済みの天気と観測時刻を集約。テキスト保存と集中表示を用意しています。
- **KNOWLEDGE**：直近300保存文書の本文一致検索。複数語はAND検索。一致箇所と文書IDを表示します。UTF-8のTXT/MD/CSV/JSON/LOGを確認してから文書として取り込めます。意味検索・PC全体のファイル走査ではありません。
- **VISION**：JPEG/PNGファイル、カメラ、利用者が選んだ共有画面から静止画を用意し、ローカルOllamaの画像対応モデルに質問。モデル検出は`/api/show`の`vision`能力に基づきます。モデルの自動ダウンロード・クラウド代替送信は行いません。画像はログや文書に保存しません。カメラ・共有画面は静止画化、パネル収納、背景タブ化で停止します。
- **VOICE**：手動開始の呼びかけ待受。設定した呼びかけ名に続く用件を入力欄へ入れます。任意の自動送信をオンにしたときのみ送信し、既存のクラウド承認フローを維持します。通常音声入力との併用を防ぎ、背景タブでは停止。ブラウザー提供元へ音声が送られる場合があります。専用常駐プロセスによる画面を閉じたままの常時待受ではありません。
- **SPATIAL**：OBJ/STLモデルを端末内でワイヤーフレーム表示。ドラッグ・矢印キーで回転、拡大、15fps上限の任意自動回転。10MB・STL6万三角形まで、描画は最大12,000辺に間引きます。形状のXYZ範囲を表示しますが、単位・製造寸法・体積・強度を保証するCAD/解析機能ではありません。
- **DEVICE**：Windowsのメモ帳・電卓・エクスプローラー起動、音量・ミュート・再生・曲送り。任意コマンドやプロセス強制終了は実装しません。表示はWindowsに要求を渡した結果であり、再生アプリの状態を実測した結果ではありません。
- **CONNECT**：Home Assistantの実状態取得、照明・スイッチ・ファンの確認付きオン／オフ。Microsoft Graphの受信箱15件と7日間の予定40件までを読み取り専用で取得。メール送信、既読化、外部予定の作成はしません。取得内容はAIや研究ログに送りません。背景タブ化・「表示を消去」で画面から破棄します。
- **LAB**：四則演算・剰余・制限付き累乗、長さ・重さ・時間・速度・データ量・温度の単位変換、文字数・空白除外文字数・空白区切り語数・行数・SHA256。外部APIへ送りません。
- **NEWS**：BBC WORLD / NASA NEWSのRSS見出し・配信時刻・原文リンクを手動取得。失敗時にダミー記事を表示しません。
- **NETWORK**：バックエンドPCの接続状態数と待受ポート・PID・プロセス名を要求時だけ取得。OS制限時は取得失敗と表示します。接続本文の読取・脅威判定は行いません。
- **SYSTEMS**：実装・必要条件の一覧、除外した映画表現、ブラウザーAPI、設定の有無、Ollama疎通・モデル利用可否の診断。設定ありと接続確認済みは区別します。

チャットでも `タスク追加：実験結果を整理する` / `タスク一覧` / `予定一覧` / `文書検索：ローカル CPU` を処理できます。カードは実際の戻り値から作成します。

### 接続設定

サーバー側の`.env`または環境変数へ設定し、再起動します。キー・トークンは画面に表示せず、ブラウザーに渡しません。

```dotenv
JARVIS_HOME_URL=http://homeassistant.local:8123
JARVIS_HOME_TOKEN=発行したHome_Assistantトークン
JARVIS_GRAPH_TOKEN=Microsoft_Graphのアクセストークン
```

Graphは組織・アカウント側でMail.Read / Calendars.Readの同意が必要です。認証フローやトークンの更新・発行はこの画面では行いません。Home Assistantは接続先に登録済みの機器が必要です。画像認識は`OLLAMA_HOST`がHTTPのlocalhost/127.0.0.1/::1である場合に限定します。カメラ・画面共有はlocalhostまたはHTTPSとブラウザーの許可が必要です。

この拡張のプライベートAPIとPC操作は、バックエンドPC内の同一オリジンからの操作に限定します。別PC・スマホからは使えません。予定JSONは端末に保存され、JSON/ICS書出には予定の内容が含まれます。チャットから実行したタスク・文書検索は従来の会話・ツール記録の対象です。

比較一覧と実機確認状況は `docs/JARVIS_CAPABILITY_AUDIT.md` にまとめています。条件がないと使えない機能を実現不可能として除外せず、未実装の範囲も残しています。


## AUDIO：音声・接続・回答文体（2026-11-01）

既存の3列配置と常設AIコアを保ち、AUDIOボタンから音声と接続の設定を操作できます。AIコア内のLINK表示からも開けます。

- 波形は音声入力中にWeb Audio APIで採取したマイク信号だけを描画。未使用時は平らな基準線です。認識中の字幕もコア内に表示し、入力欄へ反映します。認識字幕はファイルへ自動保存しません。
- 読み上げの声・速度・高さを選択して試聴できます。実際の読み上げに設定を適用し、ブラウザーの発話イベントと発話位置を表示します。出力音声の振幅はWeb Speech APIから公開されないため表示しません。利用する声により、提供元へ文章が送られる場合があります。
- 回答文体は標準／簡潔／詳しくから選びます。通常のAI推論プロンプトに反映し、キャッシュも文体ごとに分離します。ツール結果の定型書式は変更しません。クラウド確認前の追加送信はありません。
- HTTP往復時間はブラウザーからAIサーバーの/system/clockを取得して実測。手動または表示中に10秒間隔で測定し、直近30件を表示・JSON保存できます。インターネット全体のPingではなく、サーバー処理時間も含みます。失敗時は取得失敗と表示し、ゼロや直前値で埋めません。
- PROCESS LOGは実際のSSE処理イベントを直近100件表示・保存します。要求文や字幕をログ保存に含めません。

音声設定と文体の選択だけをブラウザーに記憶します。マイクや読み上げは初回表示で自動開始しません。音声入力の対応状況はブラウザー・OSに依存します。

## APPLE：iPhoneカレンダー・リマインダー（2026-11-01）
